# Greenland CRM

Android-приложение для мастеров/сервисной службы: клиенты, заявки, назначение мастеров,
офлайн-переписка по заявке.

## Стек

- Kotlin + Jetpack Compose (Material 3), MVVM
- Hilt — dependency injection
- Room — локальная база (офлайн-first, всё пишется на устройство мгновенно)
- WorkManager — фоновая синхронизация, когда появляется сеть
- Navigation Compose

## Как открыть и собрать (VS Code)

1. Откройте папку `crm_greenland` в VS Code.
2. Инструменты сборки уже лежат в проекте (не нужно ничего ставить отдельно):
   - `.tools/jdk-17.0.2` — JDK для Gradle (см. `gradle.properties: org.gradle.java.home`)
   - `local.properties` — путь к Android SDK
3. Собрать debug-APK:
   ```bash
   ./gradlew assembleDebug
   ```
   Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
4. Установить на подключённое устройство/эмулятор:
   ```bash
   ./gradlew installDebug
   ```

## Функционал (v1)

- **Заявки** — список с фильтром по статусу (Новая / В работе / Выполнена / Отменена),
  карточка заявки, назначение мастера, переписка по заявке.
- **Клиенты** — список с поиском, карточка клиента с историей его заявок.
- **Мастера** — список, вкл/выкл активности.
- Аналитика и графики — отложены, будут добавлены отдельным этапом.

## Офлайн-протокол

Всё (клиенты, заявки, мастера, сообщения) пишется сразу в локальную базу Room —
приложение полностью работает без интернета. Каждая запись помечается `syncState`
(`PENDING` / `SYNCED`). Как только появляется сеть (отслеживается через
`ConnectivityManager`, без поллинга — `data/sync/ConnectivityObserver.kt`),
`SyncManager` ставит в очередь `WorkManager`-задачу `SyncWorker`, которая проходит
по всем `PENDING`-записям и отправляет их через интерфейс `SyncApi`.

Сейчас `SyncApi` реализован заглушкой (`LocalOnlySyncApi`), которая просто
подтверждает отправку — бэкенда для синхронизации между устройствами пока нет.
Когда он появится, нужно будет:

1. Написать реальную реализацию `SyncApi` (HTTP/WebSocket-клиент) и подключить её
   вместо `LocalOnlySyncApi` в `di/SyncModule.kt`.
2. Остальной код (репозитории, `SyncWorker`, UI) менять не придётся — они работают
   только через интерфейс.

Индикатор в шапке приложения показывает состояние: офлайн / идёт синхронизация (N) /
синхронизировано.

## Структура

```
app/src/main/kotlin/ru/greenland/crm/
  data/local/       Room: entity, dao, конвертеры, CrmDatabase
  data/repository/  репозитории (единая точка правды для UI)
  data/sync/        офлайн-протокол: ConnectivityObserver, SyncManager, SyncWorker, SyncApi
  di/               Hilt-модули
  ui/theme/         чёрно-белая тема
  ui/navigation/    маршруты и NavHost
  ui/orders/        заявки: список, карточка (+ переписка), форма
  ui/clients/       клиенты: список, карточка, форма
  ui/masters/       мастера: список, форма
```
